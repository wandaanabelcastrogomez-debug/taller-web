Cómo publicar tu página

  1. Pulsa Copiar archivo completo. Reúne el HTML, el CSS y el JavaScript en un solo documento.
  2. Pégalo en un editor de texto (Bloc de notas, VS Code) y guárdalo como index.html.
  3. Haz doble clic en el archivo para verlo en tu navegador.
  4. Para ponerlo en internet, sube index.html a un servicio gratuito como GitHub Pages o Netlify.
